# Profile media

The README artwork gallery uses the latest supplied asset batch:
`hero-banner.png`, `about-grimoire.png`, `skills-magic-circle.png`,
`projects-mission-board.png`, `contributions-kingdom.png`,
`contact-banner.png`, `developer-portrait.png`, and `id-portrait.png`.
Decorative files live under `decorative-assets/`. The main SVG sections keep
their own readable compositions so baked-in text from source artwork cannot
collide with or crop the profile copy.

The supplied `gemini_generated_video_967f96b0.mp4` is embedded with native
controls and the hero banner as its poster. GitHub may sanitize video playback
in some profile views; the fallback link remains available in the video block.

No audio track is used: GitHub profile images do not autoplay audio, and
adding sound would reduce compatibility and accessibility.
